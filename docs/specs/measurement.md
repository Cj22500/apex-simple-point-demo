# Spec: Survey measurements (point-to-point)

**Status:** accepted · **Owner:** Simple-Point Lite · **Implemented in:** `frontend/src/geo/measure.ts`, `backend/app/core/measure.py`

## Purpose
Surveyors measure distances and slopes directly on a point cloud and report them in a survey deliverable. The values must be trustworthy to 0.1 mm, which is the resolution surveyors expect when a value is shown with 4 decimals in metres.

## Frame and conventions
- Internal frame: `[E, N, H]` metres (easting, northing, orthometric height).
- In JGD2011 plane rectangular coordinates, **X = northing and Y = easting** (Japanese surveying convention, EPSG:6677 axis order). The UI and SIMA/DXF exports label values in that convention. Internal math always uses `[E, N, H]`.
- All math in float64. Coordinates are rebuilt as `nodeOrigin (float64) + offset (float32)` (see ARCHITECTURE.md §Precision), never from depth buffer values.

## Outputs
| Quantity | Formula |
|---|---|
| ΔE, ΔN, ΔH | `b − a` per axis |
| Horizontal distance | `hypot(ΔE, ΔN)` |
| 3D (slope) distance | `hypot(ΔE, ΔN, ΔH)` |
| Grade % | `ΔH / horizontal × 100` (signed: + uphill a→b) |
| Grade ° | `atan2(ΔH, horizontal)` in degrees |
| Vertical pair (horizontal = 0) | grade = `null`, shown as "vertical" |
| Polyline length | sum of 3D segment lengths |
| Polygon area (plan) | shoelace on (E, N), absolute value |

## Acceptance criteria
1. Every case in `shared/golden/measurements.json` passes in **both** Python and TypeScript with |error| ≤ **1e-4 m** (0.1 mm). Target ≤ 1e-6 m. Grade ≤ 1e-6 % and ≤ 1e-6°.
2. Zero-length and vertical pairs return `null` grades without throwing or returning NaN/Infinity.
3. Precision proof: the "0.1 mm separation at Tokyo scale" case **fails** when coordinates are stored as absolute float32 (demonstrates why), and **passes** with origin + float32 offset reconstruction.
4. Display: lengths are formatted with 4 decimals (m), grades with 3 decimals (%) and 4 decimals (°).

## Ground truth
Generated by `scripts/make_golden.py` using 50-digit `decimal` arithmetic, independent of the code under test.
